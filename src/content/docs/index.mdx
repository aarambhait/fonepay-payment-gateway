## What makes these docs different

- **Every signing example is tested.** The code on these pages runs in CI against independently computed values.
- **Documentation gaps are called out.** Vendor documents contradict themselves in places. We list them on a [known issues](fonepay/known-issues/) page so you can ask the right questions.
- **No secrets, ever.** We use placeholders. Never paste real keys into any website or chat.
